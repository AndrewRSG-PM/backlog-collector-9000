ЯК ПІДКЛЮЧИТИ BK9K ДО CLAUDE
==============================

Файл BK9K-CONTEXT.md містить повну технічну документацію по BK9K:
архітектура, скрипти, Float API, типові проблеми і фікси, всі налаштування.

Якщо додати його в Claude як Project Knowledge — можна вільно ставити
питання по BK9K і просити Claude розібратись в будь-якій проблемі.


ЯК ДОДАТИ:
----------

1. Відкрий claude.ai → зліва знайди свій проект або створи новий (+ New Project)
2. Всередині проекту → "Add content" або "Project Knowledge"
3. Завантаж файл BK9K-CONTEXT.md (або просто скопіюй і встав текст)
4. Готово — Claude в цьому проекті знатиме весь контекст BK9K


ЩО Є В ФАЙЛІ:
--------------

1.  Що таке BK9K і для чого (призначення, URL, правила)
2.  Архітектура (React SPA → GitHub Actions → Float/Monday/Discord)
3.  GitHub PAT — що це, де зберігається, які права потрібні
4.  GitHub Secrets — повний список з поясненням кожного
5.  Скрипти float-check.js і order-sync.js — що роблять, змінні середовища
6.  Float API — офіційний vs внутрішній (Playwright + session cookie)
7.  FLOAT_SESSION_COOKIE — навіщо, як отримати покроково, як часто оновлювати
8.  GitHub Actions Workflows — всі чотири, inputs кожного
9.  PM Attribution — як визначається відповідальний PM для задачі
10. pm_discord.json — структура, всі імена PM (Float name vs реальне ім'я)
11. Exceptions — всі типи виключень, як працюють
12. Банери на Dashboard — коли з'являються і що означають
13. Правила — Float READ ONLY, Monday тільки Order column
14. Типові проблеми і фікси (8 задокументованих кейсів)
15. Структура файлів репо
